# 流域水库调度指标预计算与看板治理工具

面向防汛值班室的纯前端（React + TypeScript + WebWorker + IndexedDB）工具。所有数据保存在浏览器
IndexedDB 内，运行时不依赖后端；水位→蓄水换算、水量平衡、三类调度指标全部由可复算的纯函数引擎产出，
看板/图表/明细/简报/复盘只能读取**同一次锁定运行**的结果，不允许各页面直接读取“最新文件”。

## 1. 核心计算口径（与页面实现一一对应）

### 1.1 水量平衡方程（`src/lib/balance.ts`）

对每个固定时间网格区间 [t1, t2]：

```
R = S(t2) − S(t1) − [ ∫Q入dt − ∫Q出dt + P×A − 蒸发×A + 调入量 − 调出量 ]
```

- 流量积分（`src/lib/integrate.ts`）：相邻读数**实际区间秒数**梯形积分；区间两端缺读数、存在显式
  缺失/作废记录、量纲不相容、采样间隔 > 1.5×名义步长（断面故障）均判覆盖不足，**不以零补齐**。
- 水位→蓄水（`src/lib/curves.ts`）：按采样时刻**当时有效且已审批**的库容曲线线性插值，超曲线范围
  不外推；区间两端曲线版本不同则在事实上标记 `curveSwitched`。
- 雨量/蒸发（`src/lib/rainfall.ts`）：分区雨量按水库面雨量权重加权，再乘以区间中点有效库面面积
  折算水量；重叠雨量**按修订关系替代而非累加**，无修订关系的重叠直接判不可闭合。
- 跨库调水：该水库从无此类业务读数时按 0 计且闭合；一旦存在调水业务，某时段缺测仍判覆盖不足。
- 残差超测量容差（`max(绝对容差, 比例容差×量级)`）时，事实列出**未闭合来源**，绝不把差额塞入“损耗”。

### 1.2 三类指标（`src/lib/indicators.ts`，同一运行一次发布）

1. **防洪余量** = 规则汛限库容 − 已确认蓄水量；规则重叠/缺失或蓄水不可确认时为待核。
2. **近期来水压力** = 指定窗口内可确认净入库量 / 防洪余量，同时给出由各平衡项不确定度合成的
   **未知范围**与压力比区间；窗口内任一区间不可确认则指标待核。
3. **泄洪空间** = 当前净入库范围（含未知量）延续至下一决策时点时，回到规则目标库容所需的出库
   流量范围，并计算与下游允许泄流范围的**差额**（正值表示允许泄流不足）。

### 1.3 运行锁定与两种物化设计

- 每次运行固定：资料截止点（`receivedAt <= cutoff` 才纳入快照，迟到雨量被确定性排除）、曲线版本、
  规则版本、容差、时间网格，形成不可变 `RunSnapshot`。
- **物化设计**：WebWorker 预计算“水库—时段平衡事实”并落 IndexedDB，看板切换与相邻区间残差比对快；
  **按需设计**：只保留快照与积分计划，下钻时在 Worker 内用**同一引擎、同一版本与容差**即时求值。
  设计建议（`adviseDesign`）依据文件规模、值班响应时限与复盘粒度自动给出。

### 1.4 下游断面风险范围推导（`src/lib/riskRange.ts`）

下游断面传感器故障时，**不把邻近断面值当作该断面实测，也不输出单一替代水位/流量**，只输出风险
时间段与可能范围，分四类：**已确认安全 / 已确认超限 / 可能超限 / 不可判定**。

- **两类区间来源（均强制标注 `inferred=true`，与实测 `measured` 严格区分）**
  1. **工程批准传播（engineering_propagation）**：依据经审批的传播时差窗口与允许衰减/增幅界，把参考
     断面在 `[t-τmax, t-τmin]` 窗口的观测做区间传播；复杂回水按 `backwaterWiden` 加宽，未校准/校准
     到期按 `calibrationRelax` 放宽，活跃支流叠加贡献界（无测站支流只给界不给点估计）。规则可解释、
     不依赖长历史，复杂回水条件下范围较宽。
  2. **条件关系拟合（conditional_fit）**：用历史“双站同步完好”时段 OLS 拟合
     `target = slope×ref + intercept`，以残差 90 分位给预测带；日常工况比工程界更紧凑。当前雨势、
     闸门状态、季节或参考值量级超出训练环境包络（罕见暴雨/结构变化）时判**失配并回退工程界**，
     样本不足 `MIN_FIT_SAMPLES` 时不采用拟合来源。
- **分类规则**：推导上界 ≤ 承压线 → 已确认安全；下界 > 承压线 → 已确认超限；区间跨越承压线 →
  可能超限；无可用参考/模型或全部失配 → 不可判定（建议立即人工巡测，不得断言安全或超限）。
- **证据纪律**：同一参考站同时支撑多个目标断面时标记 `independent=false`（非独立证据）；多个参考站
  的结论取**区间并集**，绝不平均或加权收敛。
- **待复核与版本**：故障结束时刻与替代推导关系重叠的区间标记 `pendingReview`；恢复实测后只形成
  新的风险版本（version 递增），不回写历史推导版本。
- 风险分段与平衡事实**同网格、同快照**，在同一 Worker 内计算；物化运行落 `risk_segments` 库，
  按需运行经 ondemand 通道即时推导，两条路径同一引擎、结果一致。

## 2. 本地启动

要求 Node 22（本仓库在 Node 22.14 / npm 10.9 下验证）。

```bash
npm install --no-audit --no-fund
npm run dev        # 开发服务器，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览生产构建，http://localhost:4173
npm run test       # vitest 单元测试 + 端到端集成测试（共 41 个用例）
```

> 若本机 npm 缓存目录权限异常，可指定项目内缓存：
> `npm install --cache ./.npm-cache --no-audit --no-fund`

### Docker 一键启动

```bash
docker compose up --build
# 访问 http://localhost:8080 （nginx 托管 dist 静态产物，含 SPA 回退与健康检查）
```

## 3. 测试账号与使用流程

本工具为值班室本地单页应用，**无登录体系**；并发批注场景通过批注面板的“作者”下拉模拟两个值班
页面（值班员甲 / 值班员乙 / 防办值班长），无需任何账号密码。

标准验收流程：

1. 打开「资料接入」→ 点击 **播种内置演示数据集**（也可用「导入 CSV」上传 `samples/sample-readings.csv`）。
2. 打开「平衡运行台」→ 选择截止点预设：
   - `RUN1 06:30`：08:00 才补传的迟到雨量被排除；
   - `RUN2 09:30`：迟到雨量已纳入。
   点击“锁定快照并在 WebWorker 中运行”，完成后“选为看板运行”。
3. 「调度看板」查看地图、KPI、过程图表、指标明细与值班简报（全部同源同运行）。
4. 「断面风险」查看四个河道断面的风险时间线（格＝一个网格区间）与分段明细，点击任一格查看区间来源、
   参考证据链（含非独立标记）、支流贡献、待复核与版本、建议限制；四类 KPI 可点击过滤。
5. 「复盘回查」从风险结论下钻到参与区间、换算曲线版本、六个平衡项与原始读数证据，并做字段级批注。

## 4. 内置验收样例（六类场景）

| 场景 | 数据位置 | 预期表现 |
| --- | --- | --- |
| 迟到雨量 | z2 分区 05~06 时次 08:00 接收 | RUN1 青溪河 05~06 区间覆盖率不足不可闭合；RUN2 同区间闭合 |
| 跨库调水 | 青溪河调入 20 m³/s、白沙河调出 10 m³/s | 平衡项以正确符号计入，集成测试校验水量 = 流量×3600s |
| 库容曲线切换 | 白沙河 03:00 起 BS-S-2019→BS-S-2026 | 事实标记换版并保留 t1/t2 两个曲线 ID |
| 断面故障 | 白沙河 04:00 入库流量显式缺失 | 03~04 区间残差为 null、指标待核，缺失不补零 |
| 并发批注 | 复盘页两个作者同时编辑 | 不同字段各自保留；同字段冲突较新者胜并留痕，无整单覆盖 |
| 大文件下钻 | 东风水库 5 天 10 分钟级流量（每序列 721 点，入库+出库共约 1442 条） | 120 个小时区间全部闭合，证据链每区间 20+ 条原始读数 |

另含：雨量修订替代（01~02 时次 8mm 被 12mm 修订，不累加为 20mm）、青溪河 02:00 可疑水位制造
+50,000 m³ 超差残差（未闭合原因列明且无“损耗”项）、西岭草稿库容曲线 + 规则适用期重叠导致全指标待核。

### 4.1 断面风险推导验收样例（「断面风险」页，默认运行网格 00:00~06:00）

| 场景 | 数据位置 | 预期表现 |
| --- | --- | --- |
| 传感器故障 | 白沙河承压断面 sec-b 03:00~05:00 探头堵塞（校准到期），显式缺失 | 故障区间无单点替代值；条件关系推导依次给出**可能超限**（03~04）与**已确认超限**（04~05），全部标注“推导·非实测” |
| 支流汇入 | sec-b 左岸无测站支流 03~05 时闸控活跃，贡献界 [8,20] | 推导区间叠加支流贡献界，限制说明“支流无测站只能给界”；非活跃时段不叠加 |
| 罕见暴雨 | 04~05 时 z3 面雨强 9mm/h，超出 sec-c 条件关系雨强包络 [1,6] | 条件关系**失配回退工程传播**，来源徽标切为“工程传播推导”，限制列明包络失配；05~06 区间工程传播判**可能超限** |
| 恢复实测 | sec-b 05:00、sec-c 06:00 恢复；sec-d 04:00 起开放故障且关系仅草稿 | 恢复区间 `pendingReview` 待复核且另起**风险版本 v2**，旧推导保留 v1 不回写；sec-d 持续**不可判定**并建议人工巡测 |
| 非独立证据 | 参考站 sec-a 同时支撑 sec-b 与 sec-c（两条已审批关系） | 证据链标 `independent=false / 非独立×2`；多参考站结论取区间**并集**而非平均 |

> 演示集另含 5 天（120 组）双站同步完好历史，供两个条件关系模型 OLS 拟合与残差 90 分位预测带估计；
> 模型与健康记录、水文关系、支流条件均随运行快照冻结，可复算。

## 5. 已执行的验证（实际结果）

以下命令均在交付环境实际执行通过：

- `npm run build`（`tsc --noEmit` 严格类型检查 + Vite 生产构建）：通过，Worker 独立分包
  `dist/assets/balance.worker-*.js`，IndexedDB 由 v1 平滑升级到 v2（新增风险主数据与风险分段 5 个库）。
- `npm run test`：**3 个测试文件、41 个用例全部通过**——引擎 17（曲线/积分/雨量/平衡/指标/并发批注）、
  风险推导 16（两类区间来源、四类分类、非独立证据并集、校准放宽、包络失配回退、支流、待复核与版本、
  不可判定保护）、端到端集成 8（含风险快照冻结与物化落库，fake-indexeddb 复刻 Worker 路径）。
- 生产构建 HTTP 冒烟（`vite preview`）：`/`、主 JS chunk、Worker chunk、SPA 回退路由 `/risk` 均返回 200。

## 6. 目录结构

```
src/
  types.ts                  领域类型（读数/曲线/规则/运行/事实/指标/批注/断面风险主数据与分段）
  db.ts                     IndexedDB 存储（v2）、修订关系、字段级批注合并、风险分段读写
  lib/
    curves.ts               曲线版本选择与线性插值（不外推）
    integrate.ts            实际秒数梯形积分与覆盖度/量纲检查
    rainfall.ts             修订去重、分区权重、雨量/蒸发折算
    balance.ts              固定网格平衡事实物化（纯函数引擎）
    indicators.ts           防洪余量/来水压力/泄洪空间指标
    riskRange.ts            断面风险范围推导（工程传播/条件拟合、四类分类、版本与待复核）
    engine.test.ts           纯函数引擎单元测试（17 用例）
    riskRange.test.ts        风险推导引擎单元测试（16 用例）
    integration.test.ts      fake-indexeddb 端到端集成测试（8 用例）
  demo/
    demoData.ts             平衡运行六类演示场景
    riskDemo.ts             风险推演示数据（故障/支流/罕见暴雨/恢复 + 5 天完好历史）
  workers/balance.worker.ts WebWorker：物化落库 + 按需即时求值（含风险分段）
  services/                 运行编排、CSV 接入与播种
  pages/                    资料接入、目录治理、运行台、看板、断面风险、复盘
  components/               地图、图表、简报、状态徽标、风险时间线、字段级批注面板
samples/sample-readings.csv CSV 接入样例（含迟到/缺失/可疑/调水/蒸发/断面风险行）
```
